# IBM Plex (self-hosted)

Canopy body (`IBM Plex Sans`) and mono (`IBM Plex Mono`) faces for M.P.A.

- **Source:** `@ibm/plex-sans@1.1.0` / `@ibm/plex-mono@1.1.0` complete woff2
- **License:** SIL Open Font License 1.1 — see `OFL.txt`
- **Loaded via:** `next/font/local` in `apps/web/src/app/layout.tsx`

Do not switch these back to `next/font/google` — Vercel Preview builds cannot depend on Google Fonts fetch at build time.
