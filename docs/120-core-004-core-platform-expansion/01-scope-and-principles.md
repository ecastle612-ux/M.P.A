**Package:** CORE-004  
**Status:** Draft — Planning

## Expansion principles

1. **Capabilities over chrome** — prefer finishing operational workflows over visual novelty.  
2. **Inherit, don’t reinvent** — STD-001 is the default home/nav law.  
3. **One authorize at a time** — slice-sized delivery with verify before the next.  
4. **Entitlement-safe** — existing AUTH / BILL / capability gates remain authoritative.  
5. **Evidence-first** — acceptance criteria and tests before “done.”  
6. **Respect CORE-003** — where cross-package order still applies, do not jump the queue without CORE-003 amendment.
