# Customer Experience Audit — COM-002

Lens: first-time buyer vs HubSpot, Monday.com, Shopify, Stripe, Linear, Notion.

---

## Comparable? Not yet — fixable

| Competitor pattern | COM-002 | Gap |
|--------------------|---------|-----|
| Pricing page → Checkout quickly | Product → Plan → Cycle → Checkout | One extra decision layer |
| Transparent public prices | Prices TBD | Blocks trust until O1 set |
| Instant trial or demo | Demo strong; trial optional | Good if demo is excellent |
| Enterprise “Contact sales” clearly separate | Present but forked late in diagram | Move earlier |
| Pay then workspace | Aligns with Stripe/Notion-ish | Must feel polished on success page |
| In-app billing clarity | Portal-heavy | Prefer Billing home like Linear/Stripe |

---

## First-time buyer critique

**What works**

- Demo without account is premium and modern.  
- Hosted Checkout is trustworthy.  
- “Creating your workspace…” is the right emotional beat.  
- Enterprise as intentional high-touch (not a broken Checkout).

**What hurts confidence**

1. **Three-axis catalog** (Product × Plan × Cycle) feels like ERP quoting, not Linear.  
2. **FO/Complete self-serve** may promise facility depth that is not operationally real.  
3. **Pay before account** feels odd if success/bind is clunky.  
4. **No public prices** in the design package — buyers compare dollars early.  
5. **Confirm Plan interim** vs future Checkout — cutover messaging must be flawless.

---

## Recommended CX amendments (mostly non-blocking except honesty)

| Change | Blocking? |
|--------|-----------|
| Default path: **Property Manager** highlighted; FO/Complete only when honest | **Blocking (A1)** |
| Collapse UI: choose Product cards → Plan toggle (Pro/Business) + Annual switch → CTA | Non-blocking |
| Enterprise CTA on pricing hero, not after Checkout intent | Blocking for journey clarity (A6) |
| Success page quality bar: progress steps, email confirmation, support | Non-blocking but high value |
| Billing & Plan as primary; Portal secondary | Non-blocking |
| Expired/canceled pages with calm copy | Blocking journey (A4) |

---

## Premium bar checklist

| Question | Today |
|----------|-------|
| Does every step have one obvious next action? | Mostly |
| Can a buyer subscribe in under 5 minutes after decision? | Only if prices clear + fewer steps |
| Does demo feel real without lying? | At risk for FO |
| Does Enterprise feel exclusive? | Conceptually yes |

---

## Verdict

Experience can reach competitor parity **after honesty + funnel simplification + polished post-pay bind**. Architecture is not the main CX blocker — **commercial honesty and decision compression are**.
