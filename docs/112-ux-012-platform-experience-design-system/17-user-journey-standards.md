# 17 — User Journey Standards

**Package:** UX-012  
**Status:** Draft — Awaiting Approval  
**Related:** Experience Architecture first-five-minutes · COM/AUTH onboarding

---

## Quality bars (every journey)

| Bar | Standard |
|-----|----------|
| **Orientation** | User knows where they are and why |
| **Next action** | Always one obvious primary |
| **Progress** | Multi-step shows progress (wizard/workflow) |
| **Recovery** | Errors don’t erase work without warning |
| **Role-fit** | Journey matches assigned portal |
| **Mobile parity** | Critical path completable on phone |
| **Trust** | Status language honest; money clear |

---

## Journey classes

| Class | Examples | UX bar |
|-------|----------|--------|
| **Activation** | First login → Setup Wizard | Guided; recovery contact; Finish |
| **Daily ops** | WO assign → complete | Speed; Command Center entry |
| **Money** | Pay rent / review statement | Clarity; receipts |
| **Communication** | Message / announce | Inbox unity |
| **AI-assisted** | Approve recommendation | Confidence + gate |
| **Support** | Escalation | Clear ownership language |

---

## First five minutes (role)

| Role | Must achieve |
|------|--------------|
| Org Admin | Sign in, see Command Center, know setup status |
| PM | See today’s priorities |
| Tenant | See pay/request path |
| Tech/Vendor | See today’s job |

---

## Anti-patterns

- Journeys that dump users on empty module hubs  
- Forced desktop-only critical paths  
- Surprise navigation resets mid-wizard
