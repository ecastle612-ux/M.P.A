# 11 — Branding Standards

**Package:** UX-012  
**Status:** Draft — Awaiting Approval  
**Related:** Canopy visual identity · UX-007 adaptive logo · BR packages

---

## Visual identity

M.P.A. brand character: **confident, calm, professional, trustworthy** (Canopy).  
Product UI is Canopy-first; marketing may be more expressive but must remain recognizable as the same brand.

---

## Logo usage

| Rule |
|------|
| Use adaptive two-logo system (UX-007 / BrandLogo) |
| Clear space ≥ wordmark height on marketing; product uses Compact/Standard modes |
| Icon-only for PWA/notification/favicon — not for primary drawer brand where wordmark fits |
| Never stretch, recolor outside tokens, or add glow |

---

## Accent colors

Canopy brand accent only for primary actions and key focus.  
Do not invent secondary “fun” accents per feature.  
Semantic status colors reserved for state — not decoration.

---

## Illustration style

Sparse, linear/spot, professional.  
Same stroke weight family across empty states.  
No clip-art chaos; no meme stickers.

---

## Photography

Real property/operations context when used.  
Avoid generic stock handshake.  
Full-bleed hero rules apply to marketing landings (user frontend rules); product ops stays dense.

---

## Marketing consistency

Same type families, accent, logo rules.  
CTAs: purchase/demo — not “Create free account” (AUTH invitation-only).

---

## Light mode / Dark mode

| Mode | Rule |
|------|------|
| **Light** | Default product |
| **Dark** | Semantic token pairs only; test contrast |
| Toggle | User preference + system; persist |

No separate “dark brand” with neon accents.
