# 23 — Role Experience Playbooks

**Package:** UX-012  
**Amendment:** A02  
**Status:** Binding (Approved with Amendments)  
**Extends:** [08 Role-based experiences](./08-role-based-experiences.md)

---

## Purpose

Complete UX expectations so every major role feels like a **purpose-built application** — same Canopy language, different jobs.

---

## Organization Administrator

| Dimension | Expectation |
|-----------|-------------|
| **Homepage** | Command Center — org health, setup/implementation progress, billing alerts, team risks |
| **Primary workflows** | Invite users, manage roles, finish setup, billing portal, recovery contact, modules |
| **Navigation** | Home · People · Settings · Billing · Portfolio (as entitled) · Inbox |
| **Daily priorities** | Incomplete setup, past due, at-risk health, pending invites |
| **Quick actions** | Invite user, View billing, Open setup, Message CS (if linked) |
| **Notifications** | Security, billing, setup stalls, org suspension |
| **AI interactions** | Setup coaching; org-level recommendations; approvals for bulk invites |
| **Success metrics** | Setup completion %; seats utilized; time-to-first-value |

## Property Manager

| Dimension | Expectation |
|-----------|-------------|
| **Homepage** | Command Center — action queue, today’s schedule, messages, Critical WOs |
| **Primary workflows** | Assign WO, lease pipeline, resident message, vendor coordinate, inspections |
| **Navigation** | Home · Work · Properties · People · Messages · More (Reports/Settings) |
| **Daily priorities** | Overdue WO, lease tasks, unread messages, renewals |
| **Quick actions** | Create WO, Message tenant, Schedule inspection, Collect/record payment (entitled) |
| **Notifications** | WO SLA, vendor accept/decline, resident messages, lease expiry |
| **AI interactions** | Urgency classify, vendor recommend, draft replies (approve to send) |
| **Success metrics** | WO completion time; clicks to assign; inbox zero rate |
