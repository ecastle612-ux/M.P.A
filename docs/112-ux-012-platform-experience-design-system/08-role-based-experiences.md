# 08 — Role-Based Experiences

**Package:** UX-012  
**Status:** Draft — Awaiting Approval  
**Related:** Canopy role experiences · AUTH-001 dashboard assignment · OPS Command Center

---

## Binding rule

Each role should feel **purpose-built** — same Canopy language, different jobs, density, and IA. Users never pick dashboards; AUTH assigns the surface.

---

## Role briefs

### Organization Administrator

| Aspect | Expectation |
|--------|-------------|
| Job | Own the workspace; people, plan, setup, risk |
| Home | Command Center: org health, priority tasks, billing alerts |
| Density | Compact–comfortable |
| Tone | Authoritative, clear ownership |

### Property Manager

| Aspect | Expectation |
|--------|-------------|
| Job | Run daily ops: WO, leasing, residents, vendors |
| Home | Action queue first; schedule; messages |
| Density | Compact |
| Tone | Decisive ops console (Canopy Operations Console) |

### Owner

| Aspect | Expectation |
|--------|-------------|
| Job | Understand performance; statements; messages |
| Home | Portfolio clarity; money; attention items |
| Density | Comfortable |
| Tone | Calm, financial clarity (OWNER-001 patterns) |

### Vendor

| Aspect | Expectation |
|--------|-------------|
| Job | Accept/schedule/complete work; invoice |
| Home | Offered/accepted jobs; today |
| Density | Touch-first |
| Tone | Direct, field-ready; VENDOR-001 frictionless |

### Facility Technician

| Aspect | Expectation |
|--------|-------------|
| Job | Arrive, fix, document, complete |
| Home | Assigned jobs + map/schedule |
| Density | Touch-first large controls |
| Tone | Minimal chrome; one job at a time |

### Tenant

| Aspect | Expectation |
|--------|-------------|
| Job | Pay, request, message, read announcements |
| Home | “What should I do today?” friendly (Tenant Home success) |
| Density | Comfortable |
| Tone | Warm, clear, low anxiety |

### Support Staff (CS / Tech Support)

| Aspect | Expectation |
|--------|-------------|
| Job | Help customers; see health/tickets context |
| Home | Staff tools + customer context panels |
| Density | Compact |
| Tone | Tooling clarity; never confuse with tenant UI |

### Master Admin

| Aspect | Expectation |
|--------|-------------|
| Job | Platform control plane |
| Home | ADMIN-003 mission control |
| Density | Compact |
| Tone | Powerful but audited; distinct staff chrome |
