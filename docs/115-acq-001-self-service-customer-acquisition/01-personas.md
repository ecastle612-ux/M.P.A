## Primary buyer personas (self-serve)

### P1 — Independent property manager (Professional)

| Attribute | Detail |
|-----------|--------|
| Portfolio | Small–mid (fits Pro limits) |
| Goal | Replace spreadsheets / fragmented tools quickly |
| Buying mode | Self-serve; low tolerance for sales calls |
| Plan | Professional (or Trial → Pro) |
| Anxiety | Price, migration, “will this work for my units?” |

### P2 — Growing operator (Business)

| Attribute | Detail |
|-----------|--------|
| Portfolio | Larger team and property count |
| Goal | Standardize ops; seats + properties headroom |
| Buying mode | Self-serve after short evaluation |
| Plan | Business (or Trial → Business) |
| Anxiety | Limits, support, upgrade path |

### P3 — Trial evaluator

| Attribute | Detail |
|-----------|--------|
| Goal | Prove fit before card commitment (or with Trial Checkout per open questions) |
| Plan | `trial` |
| Constraint | Same provision + Guided Setup path as paid; entitlements capped |

## Sales-assisted persona (not ACQ self-serve Checkout)

### P4 — Enterprise / complex portfolio

| Attribute | Detail |
|-----------|--------|

## Non-buyer personas (must not acquire via ACQ)

| Persona | Correct path |
|---------|--------------|
| Tenant / resident | Portal invite / lease path — not public pricing Checkout |
| Owner investor | Owner portal invite — not org purchase |
| Vendor | Vendor token / invite — not org purchase |
| Team member of existing org | Org Admin invitation (AUTH-001) |
