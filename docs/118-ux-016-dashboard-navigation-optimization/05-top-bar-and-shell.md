# 05 — Top Bar and Shell

**Package:** UX-016  
**Status:** Draft — Ready for Approval  
**Date:** 2026-08-05

---

## Top bar contents (binding)

The top bar contains **only**:

1. **Search** (global / command entry)  
2. **Notifications**  
3. **Current Organization** (switcher when multi-org allowed)  
4. **Profile** (account menu)

Everything else belongs in the **sidebar** (desktop) or **More / bottom nav** (mobile).

---

## Allowed adjacent chrome

| Element | Allowed? | Notes |
|---------|----------|-------|
| Brand mark / logo | Yes | Canopy / BrandLogo rules; not a content dump |
| Property scope control | Yes, if already in shell | Prefer Greeting place signal + existing filter patterns; do not invent a second portfolio browser in the top bar |
| AI entry | Optional icon | Must not displace the four primaries; prefer integrated Command Center AI per UX-012 |
| Environment banners | Yes | Impersonation / master-admin / read-only — operational necessity |

---

## Forbidden in top bar

- Full primary nav links (Maintenance, Leases, …)  
- Marketing CTAs  
- Dense KPI strips  
- Multiple competing icon clusters without labels for critical actions  

---

## Shell relationship

| Region | Job |
|--------|-----|
| Top bar | Find · be notified · switch org · account |
| Sidebar / bottom nav | Go to workflows |
| Main canvas | Do the work (dashboard hierarchy) |

Navigation remains supportive. The canvas answers the five-second test.
