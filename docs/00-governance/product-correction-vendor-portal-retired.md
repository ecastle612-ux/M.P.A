# Product Correction — Vendor Portal Retired

**Type:** Product correction (not a gated workstream authorize)  
**Date:** 2026-07-26  
**Status:** Implemented in application  

---

## Decision (authoritative)

The **Vendor Portal** has been removed from the M.P.A. product.

- Vendors are **not** authenticated M.P.A. users.
- Vendors interact **only** through secure invitation/action links (email/SMS) generated by M.P.A. (`/v/[token]`).
- Internal users continue managing vendors through the **Vendor Directory** (`/vendors`) and **Facility Operations**.

This correction is **not** part of PMX-004 Phase 9 and does **not** authorize new workstreams.

---

## Application effects

| Removed | Preserved |
|---------|-----------|
| `/portal/vendor` experience (redirects to `/vendor-access`) | Vendor Directory + profiles + assignment |
| Vendor portal navigation / hub card / Master Admin portal test | Secure job links accept / decline / start / complete / photos / notes |
| Vendor login landing → portal dashboard | Facility Technician dashboard + internal WO workflow |
| Setup invite template role “Vendor” (portal membership) | Vendor invoices / receipts / performance (internal) |

Legacy membership role `vendor` (if present) lands on `/vendor-access` with retirement notice — no portal session surface.
